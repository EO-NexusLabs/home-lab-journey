# Lab 01: Core Linux CLI Commands & Navigation

## 🎯 Objective
Document and practice essential Linux terminal commands for file manipulation, system navigation, and directory management within CachyOS.

## 🛠️ Key Commands Executed
* `pwd`: Print working directory.
* `ls -la`: List files with detailed permissions and hidden entries.
* `mkdir -p`: Create nested directories safely.
* `touch`: Create empty files or update timestamps.

- Successfully configured local SSH keys for Git integration.
- Navigated directory trees and established base repository structure.
